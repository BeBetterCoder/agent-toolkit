# TypeSafe Runtime Routing

For fast, structured semantic judgments, use the `jev-decision` skill's value
gate. The user does not need to name TypeSafe, a skill, MCP, a primitive, or a tool.

- Let Codex decide locally whether TypeSafe adds material value. Never call
  TypeSafe to decide whether TypeSafe should be called.
- Prefer TypeSafe when many independent items share one bounded Choice, Noul, or
  Score definition. Trigger from this computational shape across any domain, not
  from specific business topics.
- Keep deterministic work, research, generation, cross-item synthesis, and
  dependent multi-step reasoning with Codex.
- Prefer the repository's `jev-decision` runtime skill for making a judgment.
- An explicit `$jev-decision` invocation requests the MCP-backed judgment
  workflow; an ordinary natural-language request may trigger it implicitly.
